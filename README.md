# TECHVAULT

**Technical Knowledge. Precision Repair.**

TECHVAULT is a technician-focused repair and diagnostic reference prototype for major home appliances.

## Current prototype
- Responsive navy blue, black and gold interface
- Searchable starter symptom catalog
- Filters for TV, refrigeration, laundry, dishwasher, cooking, microwave and other appliances
- Source-verification and safety principles
- No backend, login, API keys, or private CRM data

## Accuracy and safety
Starter topics are general triage prompts, not confirmed model-specific service procedures. Consult the manufacturer's official documentation for the exact model. A symptom alone does not prove a component has failed. Electrical, gas, microwave high-voltage, and sealed refrigeration work must be handled by appropriately qualified personnel.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Upload all files and folders to a separate repository named `techvault`.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the default branch and `/ (root)`, then save.
4. Wait for publication and test on desktop and mobile.

Do not place passwords, API keys, customer records, or confidential service documents in this public repository.

## Independence
TECHVAULT is separate from and not affiliated with the TEK R US CRM.
